## 🚀 Development & Deployment

### Run Locally

```bash
# Install dependencies
npm install

# Start local dev server (http://localhost:5173/)
npm run dev

# Production build
npm run build

# Preview build locally
npm run preview
```

### Deploy to Vercel

1. Push this repository to GitHub.
2. In [Vercel Dashboard](https://vercel.com/), click **Add New Project** and select this GitHub repository.
3. Vercel automatically detects the **Vite** preset and root directory.
4. Click **Deploy** — your portfolio is live in seconds!
